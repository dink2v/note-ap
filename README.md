# Note AP — Apotek Prapatan

Workspace internal untuk merencanakan, memproduksi, dan menjadwalkan konten media sosial Apotek Prapatan.

## Pratinjau versi pertama
- Dashboard dengan ringkasan total konten, publish, dan terjadwal.
- Filter platform Instagram, TikTok, dan Facebook.
- Kalender konten bulanan.
- Content Database dengan pencarian dan filter status/platform.
- Kanban Board horizontal dengan alur Ideation sampai Published.
- Form Detail Content untuk brief, hook, body, visual, CTA, caption, hashtag, dan notes.
- Analytics dan Report dasar.
- Tampilan responsif desktop dan HP.

## Menjalankan
Repository ini adalah frontend statis. Buka `index.html` melalui GitHub Pages atau server lokal sederhana.

## Warna identitas
- Teal: `#00B3B3`
- Orange: `#FF5A2F`

## Catatan data
Versi pratinjau menyimpan data contoh dan perubahan konten di localStorage browser. Data belum tersinkron antarperangkat. Backend Google Apps Script dan Google Sheets akan dibuat pada tahap integrasi berikutnya.

## Struktur
- `index.html` — kerangka aplikasi.
- `styles.css` — desain responsif.
- `app.js` — navigasi dan interaksi frontend.
