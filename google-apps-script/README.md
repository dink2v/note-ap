# Note AP — Google Calendar Bridge

This folder contains the Google Apps Script backend used by the Note AP GitHub Pages app.

## What it does

- Uses the Apotek Prapatan Google Sheet as the sync database.
- Creates and updates matching Google Calendar events.
- Imports events created directly in the configured calendar into Note AP.
- Uses **C — Last Saved Change Wins** when a Note AP record and its linked Calendar event both changed.
- Stores the sync mapping and activity log in the spreadsheet tabs `NoteAP_Contents` and `NoteAP_SyncLog`.

## 1. Create the Apps Script project

1. Open [Google Apps Script](https://script.google.com/).
2. Create a standalone project, for example **Note AP Calendar Bridge**.
3. Open `Code.gs` in this repository and copy its complete contents into the Apps Script editor.
4. In **Project Settings → Script Properties**, add:

| Property | Value |
| --- | --- |
| `NOTEAP_API_TOKEN` | A long random secret generated by you |
| `NOTEAP_SPREADSHEET_ID` | `132FD2WyRTDOaZbOq_ABlyR1SWtesRh5i0XWkE_7p54w` |
| `NOTEAP_CALENDAR_ID` | `primary` or the ID of the shared Apotek Prapatan calendar |

5. In Apps Script **Project Settings**, set the time zone to **Asia/Jakarta**.

## 2. Deploy as a Web App

1. Select **Deploy → New deployment → Web app**.
2. Set **Execute as** to **Me**.
3. Set access to **Anyone**.
4. Deploy and authorize access to Google Sheets and Google Calendar.
5. Copy the Web App URL ending in `/exec`.

Use a dedicated shared calendar for Note AP if possible. If you select `primary`, the script can see/import ordinary events from the account's primary calendar too.

## 3. Connect Note AP

1. Open Note AP → **Setelan → Integrasi**.
2. Paste the Web App URL.
3. Paste the same token used for `NOTEAP_API_TOKEN`.
4. Choose **Simpan Konfigurasi**, then **Tes Koneksi**.
5. Choose **Sinkronkan Sekarang**.

The URL and token are stored in local storage on the browser/device used to configure Note AP. They are not committed to this GitHub repository.

## Important notes

- This bridge currently synchronizes the content schedule fields: title, posting date/time, platform, format, pillar, status, and IDs.
- The first successful sync creates the `NoteAP_Contents` and `NoteAP_SyncLog` tabs if they do not exist.
- Use the same shared Google account/calendar and the same Note AP workspace data when testing from multiple devices.
- The Web App is configured for public endpoint access and relies on the shared API token. Anyone who can inspect a browser where the token is stored can retrieve it. Do not use this token-based setup for a public app with untrusted users; use a proper authenticated backend for that case.
- The app currently triggers sync manually. Automatic background scheduling and complete deletion/tombstone propagation are not enabled yet.
