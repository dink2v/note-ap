FAQ

Pertanyaan yang sering diajukan

Bagaimana cara membuat konten baru?

Buka menu Konten atau Kanban, lalu pilih tombol Konten Baru atau Tambah Konten. Isi informasi konten pada formulir dan simpan.

Apa fungsi tahapan di Kanban?

Tahapan menunjukkan progres produksi: Ideation, Planning, Production, Editing, Review, Ready to Publish, dan Published. Perbarui tahap ketika pekerjaan berpindah proses.

Bagaimana mengubah referensi konten?

Buka Setelan → Referensi. Pilih kategori, tambahkan referensi, lalu gunakan aksi edit, aktif/nonaktif, atau hapus pada item yang tersedia.

Apakah data Note AP sudah tersimpan online dan tersinkron ke Google Sheets?

Belum. Saat ini data konten, Visit, referensi, dan preferensi tertentu disimpan di localStorage browser/perangkat yang digunakan. Integrasi Google Sheets belum aktif karena endpoint koneksi belum dipasang.

Apakah data bisa dibuka dari perangkat lain?

Data yang tersimpan lokal tidak otomatis berpindah ke perangkat atau browser lain. Gunakan fitur Ekspor Backup dan Impor/Pulihkan Backup di Setelan → Manajemen Data untuk memindahkan salinan data secara manual.

Bagaimana cara mencadangkan data?

Buka Setelan → Manajemen Data → Unduh Backup JSON. Simpan file di tempat yang aman. Untuk memulihkan, pilih file backup melalui menu Pilih File Backup.

Bagaimana cara menambahkan konten langsung dari Kalender?

Buka menu Kalender, lalu klik area kosong pada kolom tanggal yang diinginkan atau tekan tombol + di tanggal tersebut. Form Tambah Konten lengkap akan terbuka, sama seperti saat membuat konten dari menu Konten. Tanggal yang dipilih otomatis terisi. Lengkapi informasi konten lainnya, lalu simpan. Konten baru akan muncul di Kalender, Konten, dan Kanban.

Bagaimana cara melihat atau mengedit konten dari Kalender?

Klik kartu konten yang sudah ada untuk melihat detailnya. Pilih Edit pada detail untuk membuka form Detail Konten lengkap. Untuk mengubah tanggal publikasi dengan cepat, seret kartu ke tanggal tujuan.

Bagaimana cara menambahkan jadwal Visit?

Buka menu Visit, lalu pilih Tambah Jadwal Visiting. Isi tanggal, jam, lokasi, judul konten, talent, properti/produk, status, dan keterangan pada baris yang tersedia.

Bagaimana cara menghapus beberapa jadwal Visit sekaligus?

Di menu Visit bagian Daftar, tekan Select, centang baris yang ingin dihapus, lalu pilih Hapus Terpilih dan konfirmasi. Gunakan Pilih Semua untuk mencentang seluruh baris yang sedang tampil, termasuk baris kosong. Tekan Batal untuk keluar dari mode pilih.

Apa arti status pada jadwal Visit?

Planned berarti direncanakan, On Progress berarti sedang berjalan, Done berarti selesai, dan Cancelled berarti dibatalkan. Perbarui status sesuai kondisi jadwal.

Apakah menghapus data di Note AP bisa dibatalkan?

Penghapusan data tidak dapat dibatalkan secara langsung. Pastikan memilih data yang benar sebelum mengonfirmasi. Jika memiliki file backup sebelumnya, data dapat dipulihkan melalui Setelan → Manajemen Data.

Bagaimana jika tampilan atau data terlihat belum berubah?

Coba muat ulang halaman dengan Ctrl + Shift + R. Perlu diingat, data lokal pada browser yang berbeda tidak otomatis sama.

Catatan penting

Note AP masih dalam tahap pengembangan. Beberapa bagian menggunakan data lokal atau tampilan preview, sehingga belum semua fitur terhubung ke sumber data bersama.
